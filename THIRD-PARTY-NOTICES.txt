Optim PDF also uses components of Windows and, when the user has installed it, Microsoft Office:
- Text recognition uses the OCR engine built into Windows 10/11 (Windows.Media.Ocr). Nothing is redistributed.
- Office to PDF conversion automates the user's own licensed Microsoft Office. Nothing is redistributed.
- Digital signatures use the Windows certificate store and .NET cryptography (System.Security.Cryptography.Pkcs, MIT).

Fonts: Optim PDF embeds subsets of fonts installed on the user's PC into documents the user creates.
Fonts whose license forbids embedding (OS/2 fsType "restricted license") are never embedded.
No fonts are distributed with Optim PDF.
